# summon

Fabric 1.21.1, Java 21.

**Мод сырой** — возможны баги, вылеты и поломанные миры. Запускайте только в отдельном профиле, без других модов и ресурспаков.

```
.\gradlew.bat build
```

JAR: `build/libs/summon-1.0.0.jar` → папка `mods` инстанса Prism.

Мир должен называться `level.dat`.

Если мод «сломался» — удалите `.minecraft/config/summon_state.json`.
